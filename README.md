# 🍳 냉장고를 부탁해

> 남은 재료를 입력하면 AI가 딱 맞는 메뉴를 추천해주는 웹 서비스

![메인화면](./images/screenshot-main.png)

---

## 📌 서비스 소개

**"냉장고에 뭐 있긴 한데, 뭘 해먹지?"** 🤔

이런 고민을 AI가 해결해드립니다!
가지고 있는 재료만 입력하면, AI가 만들 수 있는 요리를 추천해줘요.

- 🎯 **타겟 사용자**: 요리 초보, 자취생, 재료 낭비를 줄이고 싶은 사람
- 💡 **핵심 가치**: 재료 입력 한 번으로 메뉴 고민 끝!

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🏠 **홈** | 서비스 소개 페이지 |
| 🍽️ **메뉴 추천** | 재료 입력 → AI 메뉴 추천 (핵심 기능!) |
| 📖 **사용법** | 서비스 이용 가이드 |

### 🤖 AI 기능 상세
- **입력**: 가지고 있는 재료 (예: 김치, 계란, 밥)
- **출력**: AI가 추천하는 맞춤 메뉴
- **실패 처리**: 재료를 입력하지 않으면 안내 메시지 표시

## 🚀 실행 및 배포 방법

## 🔑 환경 변수 설정

> ⚠️ API 키는 **절대 코드에 직접 넣지 않고** 환경 변수로 관리합니다!

Vercel 프로젝트 → **Settings → Environment Variables**에서 설정:

| 변수명 | 설명 |
|--------|------|
| `OPENAI_KEY` | OpenAI API 키 |
