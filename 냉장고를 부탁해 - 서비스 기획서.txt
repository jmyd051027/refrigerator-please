냉장고를 부탁해 - 서비스 기획서
1. 서비스 개요
서비스명: 냉장고를 부탁해 🍳

목적: 냉장고 재료를 입력하면 AI가 추천 메뉴를 제시해주는 웹 서비스

타겟 사용자: 요리 아이디어가 필요한 20~45세 직장인, 학생, 주부

2. 페이지 구성
페이지	목적	기능
홈	서비스 소개	배경 설명, "시작하기" 버튼
메뉴추천	AI 기능	재료 입력 → 메뉴 추천 결과 출력
사용법	이용 가이드	단계별 사용 방법 설명
3. AI 기능 명세
입력
냉장고 재료 (쉼표로 구분)
예: "계란, 양파, 치즈, 버터"
처리
사용자가 재료 입력
JavaScript fetch()로 백엔드 호출
api/recommend.py에서 OpenAI API 호출
메뉴 추천 결과 반환
출력
추천 메뉴명
조리법 (단계별)
소요 시간
난이도
4. 오류 처리
상황	사용자 메시지
재료 미입력	⚠️ "재료를 입력해주세요"
API 오류	❌ "다시 시도해주세요"
응답 지연	⏳ "요청이 지연되고 있습니다..."
5. 기술 스택
프론트: HTML5, CSS3, Vanilla JavaScript
백엔드: Python (Vercel Serverless)
AI: OpenAI API (gpt-5.5)
배포: Vercel + GitHub
